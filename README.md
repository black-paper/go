# Go 学習用 repository

このリポジトリは、Go 言語の学習と実践のために作成されたものです。主にフィンテック系アプリの構築を通じて、Go の文法・設計・テスト・CI/CD などのスキルを習得しています。

---

## 📌 目的

- Go 言語の基礎〜実践スキルの習得
- フィンテック領域におけるドメインモデリングとアーキテクチャ設計の経験
- 単体テストや CI/CD の実装を通じた実務力の向上
- AWS との連携や NoSQL（DynamoDB）設計力の強化

---

## 🛠️ 使用技術

| 分類         | 技術スタック                   |
| ------------ | ------------------------------ |
| 言語         | Go (バージョン: 1.xx)          |
| テスト       | testing, gomock, testify       |
| データベース | DynamoDB（予定）, SQLite（仮） |
| インフラ     | Docker, DevContainer           |
| CI/CD        | GitHub Actions                 |
| その他       | Go Modules, REST API 設計など  |
